Register new cloud

Workflow: register → Upload LAS stores the raw scan in gis-private (never served, ≤100 MB) → convert locally with PotreeConverter → octree uploads the converted folder to clouds-public/<prefix> (files over 90 MB are chunked automatically) and flips status to ready (point count read from metadata.json/cloud.js) → publish → open /lidar. Upload tracking is recorded per cloud automatically.
